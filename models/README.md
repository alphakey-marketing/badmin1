# 3D models

- `michelle.glb` — realistic human character from the three.js examples
  (https://github.com/mrdoob/three.js/tree/r169/examples/models/gltf). The character and skeleton come from
  Adobe Mixamo, whose terms allow royalty-free use in projects but not redistribution of the character as a
  stand-alone asset. Replace it with a CC0 model (for example a Polygonal Mind "100 Avatars" glTF export)
  if you need a fully open licence; any model with a Mixamo-style skeleton (`mixamorig*` bone names) works.
